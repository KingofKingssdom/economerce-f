# 🚀 Project Frontend - React + Vite

Đây là dự án Frontend sử dụng **React + Vite** để phát triển giao diện người dùng.  
---

## 📦 Công nghệ sử dụng

- ⚛️ **React 18**
- ⚡ **Vite**
- 🧭 **React Router DOM**
---

## 📁 Cấu trúc thư mục

             
🛠️ Cài đặt dự án Frontend
1️⃣ Cài dependencies     : npm install
2️⃣ Chạy dự án           : npm run dev
3️⃣ chạy mặc định tại    : http://localhost:5173/
